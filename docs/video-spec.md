## 2. 主界面布局

### 2.1 覆盖范围

- 启动台覆盖 **y=0 … 690** 的整块"工作区"（1280 宽）；**Windows 任务栏（y≈690–720）在它之上仍然可见、清晰、未被模糊**（全程可见：t=7.6 / 9.9 / 13.2 / 65.1 / 74.8…）。
- 复刻建议：Electron 用无边框窗口铺满工作区（`screen.getPrimaryDisplay().workAreaSize`），`alwaysOnTop` 不必，但保证任务栏可见；不要做成真全屏。

### 2.2 背景

- 内容 = **当前桌面壁纸 + 强高斯模糊 + 中性黑色蒙层**。
- 蒙层实测：同一处壁纸在"桌面"（t=76.8，清晰）与"启动台内"（t=76.4）的亮度比 **0.744（RGB 三通道一致 0.741/0.749/0.747）** → 等价 **rgba(0,0,0,0.256)** 叠加。
- 模糊半径：用清晰壁纸做多半径高斯模糊与启动台背景做归一化相关（NCC），峰值落在 **σ≈12–16 视频像素（≈18–24 CSS px）**；视觉上细曲线全消失、只剩大色块。**（模糊强度受视频里"模糊=默认"影响，属估计，标不确定）**
- 背景是**活的**：壁纸本身在缓慢变色（桌面帧 0–3s 白蓝 → 5–7s 粉红 → 8s 蓝），启动台背景随之变色，不是静态图。
- 启动台内**没有任何顶部/底部栏、没有标题、没有关闭按钮**；顶中央只有搜索框，底中央只有页指示器。

## 3. 图标与标签（细节）

- **形状**：完全沿用应用自身图标（Windows 快捷方式的 32/48/256 多尺寸 icon），**不做统一圆角方形托底、不加玻璃拟态底板**。方形应用图标自带圆角，圆形 logo 就显示为圆形。
- **阴影**：每枚图标下有一层柔和暗影（贴合图标轮廓），用于在浅色模糊背景上拉出层次。
- **hover 态**：**未观测到**明显的 hover 高亮/放大/底框（整段视频鼠标数次停在图标附近但未停留；t=24.4、t=74.8 光标位于图标区，图标无变化）。→ 复刻时可自定（建议轻微 1.04 放大 + 极淡圆角底），但请标明是补充设计，不是视频证据。
- **点击动效**：未观测（视频未点击任何图标启动应用）。
- **分组/文件夹**：「外观 → 九宫格分组（分组图标最多显示九个应用）」当前为**关闭**，且全片**没有出现过分组文件夹的外观或展开动画**。只能确认设置项存在；文件夹视觉/动画**没有素材**，复刻需另定设计并注明。
- 图标来源与"桌面同步"：视频里**没有"桌面图标同步"开关**。相关的是「应用位置」里对*扫描来源*的开关（开始菜单/公共开始菜单/桌面/公共桌面/已安装应用），以及「应用管理」里对单个应用的启用开关。视频里桌面本身是空的（无桌面图标）。

## 11. 行为细节（观测 + 推断分级）

**有直接证据**
1. 启动台是铺满工作区的覆盖层，任务栏保持可见（全片）。
2. 翻页是水平滑动，且存在多个页（≥3 个页面内容被看到）。
3. 搜索是实时过滤；无结果时中央文案 `没有找到应用`。
4. 网格空白处右键 → 10 项主菜单；菜单项 hover 有整行高亮；`排序设置` 有多级子菜单且 `自动排序` 带勾。
5. 设置窗口 6 个页签，内容如 §8；点「完成」关闭并弹底部状态条。
6. 应用管理窗口 = 搜索 + 应用清单 + 逐项开关。
7. 打开/关闭启动台的过程非常快（≈0.1s 淡入淡出）。
8. 全局快捷键（设置项显示）`Ctrl + Shift + Space`，作用是"显示或最小化 Flare Launchpad"。

**推断（无直接画面证据，需标注为设计假设）**
- 关闭启动台的方式（Esc / 点击空白 / 再次热键）：视频 t≈4.9 与 t≈76.5 的关闭原因看不到鼠标落点，**无法确认**。
- 滚轮方向与每格滚动量：翻页间隔在 9.9→13.2 之间只用了 ~2.4s 翻了 2–3 页，说明滚轮/手势可连续翻页；具体方向/阈值未知。
- 键盘导航（方向键选中、回车启动、数字键）：**未观测**到。
- 图标 hover/点击动效：未观测。
- `设为首屏`/`锁定图标布局`/`激活管理`/`重启` 的行为：只有菜单文字。
